# Site Imobiliária Alpha | Rio Preto

Landing page de alta conversão da Imobiliária Alpha (São José do Rio Preto e região).

- `Alpha Landing v2.dc.html` — versão atual do site (o `index.html` redireciona para ela)
- `Alpha Landing.dc.html` — versão anterior
- `assets/fotos/` — fotos das seções · `assets/video/` — vídeo da seção Construção
- `support.js` / `image-slot.js` — runtime do Claude Design (necessários para a página rodar)

## Rodar localmente

```bash
python3 -m http.server 8765
```

Depois abra http://localhost:8765

## Antes de publicar

- Trocar o WhatsApp de exemplo (`5517999999999`) e o CRECI (`xxxxx-J`) pelos dados reais.
